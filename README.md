# РБПО — командный проект

Репозиторий проекта по курсу [«Разработка безопасного ПО»](https://github.com/hse-rbpo-master-2026/course), НИУ ВШЭ, 2026/2027.

## Кампус — пропуска на студенческие мероприятия

Приложение для создания мероприятий, регистрации участников, выдачи QR-пропусков и контроля входа. **Сервер — Go, база — PostgreSQL, интерфейс — React и TypeScript.**

### Что можно делать

- Создать аккаунт, войти, изменить имя и пароль, завершить сеанс.
- Создать черновик мероприятия: описание, категория, место, время, открытие входа, окончание регистрации, вместимость и цвет.
- Опубликовать мероприятие, редактировать его с проверкой версии или отменить.
- Найти событие на афише и получить персональный пропуск.
- Выдать гостевой пропуск без аккаунта участника.
- Открыть пропуск на телефоне, скачать QR-код, скопировать текстовый код или распечатать билет.
- Пригласить контролёра или соорганизатора по одноразовой ссылке, отозвать приглашение или доступ.
- Погасить пропуск сканированием камеры или вводом кода. Повторный проход, другой зал/событие, отменённый или просроченный пропуск отклоняются.
- Найти участника, отменить пропуск, выгрузить CSV, посмотреть журнал проходов и действий команды.

Каждый пользователь может организовывать собственные мероприятия. Права контролёров и соорганизаторов действуют только в пределах конкретного события. Сервис не использует ChatGPT для входа.

## Быстрый запуск через Docker

Нужны Docker с Compose v2 и Node.js 24 для генерации конфигурации.

```sh
node scripts/setup.mjs
docker compose up --build -d --wait
```

Откройте адрес `APP_URL` из `.env` (по умолчанию **http://localhost:8080**) и создайте аккаунт. База изначально пустая: в ней нет демонстрационных пользователей, общих паролей и выдуманных результатов проверок. Миграции применяются автоматически при запуске сервера.

`setup.mjs` создаёт `.env` со случайными секретами и сохраняет существующую конфигурацию. `.env` исключён из Git и Docker-контекста.

```sh
docker compose logs -f app
docker compose down
```

Обычный `down` сохраняет данные в Docker volume. `down -v` удаляет данные; для обычной остановки он не нужен.

Если 8080 занят, измените **оба** значения в `.env`: `APP_PORT=8081` и `APP_URL=http://localhost:8081`.

## Локальная разработка

Нужны Go 1.26+, Node.js 24 и PostgreSQL 17+.

```sh
npm ci --registry=https://registry.npmjs.org
node scripts/setup.mjs
docker compose -f compose.dev.yaml up -d --wait
```

В отдельных терминалах:

```sh
# API на localhost:8080, для запросов из Vite
APP_URL=http://localhost:5173 HTTP_ADDR=127.0.0.1:8080 node scripts/run-server.mjs
```

```sh
# Интерфейс и прокси /api
npm run dev -- --host localhost
```

Откройте http://localhost:5173. Используйте именно `localhost`, как в `APP_URL`: сервер проверяет Origin запросов. По умолчанию скрипт API использует `postgres://campus:campus_dev_only@127.0.0.1:55432/campus?sslmode=disable`; другой адрес задаётся через `DATABASE_URL`.

Для запуска собранного интерфейса непосредственно Go-сервером:

```sh
npm run build
HTTP_ADDR=127.0.0.1:8080 node scripts/run-server.mjs
```

Здесь `APP_URL` в `.env` должен соответствовать http://localhost:8080.
